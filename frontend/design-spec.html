Semantic color stays separate from category color

A node's hue says what kind of step it is; its status pill says how the run went. Success reuses the trigger green and failure the video red — but only inside status pills, never as a card accent, so a red Video Rendering node is never mistaken for a failed one.

Interface face

System grotesque — SF Pro on macOS, Segoe UI on Windows, Inter as the web fallback. Chosen for legibility at 11–13px, where a display face falls apart. Character comes from tracking, not from the family.

Data face

SF Mono / JetBrains Mono. Used for combos, durations, file names, logs and every token in this document. Ligatures off — != should look like what you typed. Tabular numerals everywhere digits line up.

Motion

One easing curve for movement, one for opacity. Everything under 260ms — this is a tool, not a title sequence.

Framer Motion presets

// The house curve. Fast out, settled landing.
export const ease = [0.32, 0.72, 0, 1];

export const panel = {
  initial: { x: 18, opacity: 0 },
  animate: { x: 0,  opacity: 1 },
  exit:    { x: 18, opacity: 0 },
  transition: { duration: 0.24, ease },
};

export const node = {
  whileHover: { y: -2, transition: { duration: 0.16, ease } },
  whileTap:   { scale: 0.994 },
};

// Console lines stream in; stagger keeps them readable.
export const logLine = {
  initial: { opacity: 0, y: 4 },
  animate: { opacity: 1, y: 0 },
  transition: { duration: 0.14 },
};

Rules

Motion earns its place by explaining a change of state. If it only decorates, cut it.

120msColour and opacity. Hover tints, pill cross-fades, focus rings.
160msSmall movement. Node lift, port scale, button press.
240msLayout. Sidebar collapse, inspector slide, console expand.
NeverDirect manipulation. Dragging, panning and zooming are 1:1 with the pointer. Any easing here reads as lag.
Reducedprefers-reduced-motion collapses every duration to ~0 and removes the running-dot pulse. State stays legible through colour and text alone.

Responsive behaviour

The canvas is the last thing to give up space.

≥ 1600Full desk. 224px sidebar · fluid canvas · 322px inspector · minimap · 194px console. The reference layout.
1400–1600Comfortable. Inspector narrows to 288px. Everything else holds.
1180–1400Tight. Minimap hides — it is the least load-bearing element on the canvas. Console drops to 160px.
900–1180Laptop. Sidebar auto-collapses to the 60px icon rail; labels return on hover as tooltips. Top-bar search shrinks; button labels stay.
640–900Tablet. Inspector becomes an overlay drawer over the canvas, dismissed by tapping the ground. Button labels drop to icons. Console collapses to its header, expandable as a sheet.
< 640Phone — read, don't author. Canvas is pinch-zoom and pan only; node dragging is disabled because a 44px touch target cannot hit an 11px port reliably. Run, watch the console, inspect a node in a bottom sheet. Editing sends you to a larger screen, and says so.

Component hierarchy

What to build, and which shadcn primitive it starts from.

ComponentBuilt onNotes
<AppShell>CSS gridOwns the three columns and the console row. The only component that knows the breakpoints.
<Sidebar>Tooltip, ScrollAreaCollapsed state persists to localStorage. Labels become tooltips on the rail.
<TopBar>Input, Button, DropdownMenu, BadgeWorkflow name is an inline contenteditable input — commits on blur and Enter, reverts on Esc.
<Canvas>React Flow (headless) or customOwns pan, zoom, marquee, snapping. Renders edges into one SVG layer beneath the node layer.
<WorkflowNode>Card, Badge, ProgressPure presentation. Takes { kind, status, durationMs, selected } and nothing else.
<NodePort>—Hit area is 24px even though the dot is 11px. Never shrink the target to match the paint.
<Inspector>Tabs, Form, Select, SwitchFields come from a per-node schema, so a new node type ships its own panel without touching this file.
<ExecutionConsole>Collapsible, ScrollArea, ProgressVirtualised past 500 lines. Auto-scroll pauses the moment the user scrolls up, and says so.
<MiniMap>Canvas 2DRedrawn on transform change only, not per frame.
<CommandPalette>Command (cmdk)⌘K — add node, jump to node, run, publish.
